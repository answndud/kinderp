# 외부 API 호출 Rate Limit 개선 완료

기준일: 2026-08-21

AI·결제 API는 현재 구현되어 있지 않으며, 외부 비용이 발생할 수 있는 알림 webhook/email 호출은 서버 outbox worker가 수행한다. 사용자 입력으로 알림을 생성하는 API에는 다음 제한을 적용했다.

- `POST /api/v1/notifications` 요청을 Redis에서 사용자 ID와 신뢰된 클라이언트 IP별로 동시에 제한
- 기본값: 사용자 30회/1분, IP 100회/1분
- 초과 시 알림 outbox에 enqueue하지 않고 HTTP 429와 `Retry-After: 60` 반환
- `NOTIFICATION_RATE_LIMIT_WINDOW`, `NOTIFICATION_RATE_LIMIT_USER`, `NOTIFICATION_RATE_LIMIT_IP`로 운영 환경별 조정 가능
- `NotificationApiIntegrationTest`에서 사용자별 제한 초과와 429 응답을 검증

검증 명령:

```bash
./gradlew compileJava compileTestJava
./gradlew fastTest
npm run docs:links
```

## Resource Limit 개선

`server.request-limits`와 Tomcat connector 설정을 추가해 요청 자원 상한을 명시했다.

- HTTP request header 최대 16KB
- 일반 요청 body 및 form POST 최대 1MB
- header 최대 100개, parameter 최대 100개
- Content-Length가 1MB를 초과하거나 filter에서 header/parameter 수를 초과하면 애플리케이션 진입 전에 HTTP 413으로 차단
- 목록 API page size는 공통 최대 100개, 감사 로그 CSV export는 최대 10,000행으로 제한
- AI API와 LLM token 사용량 제한은 현재 적용 대상 기능이 없어 N/A로 기록
- `RequestLimitFilterTest`에서 oversized body와 parameter 초과 차단을 검증
