# 요구사항·기능·코드·테스트 추적표

면접관이 한 기능을 물었을 때 `요구사항 → endpoint → service/entity → test → demo` 순서로 바로 이동하기 위한 표입니다.

| 요구사항 | 주요 API/화면 | 핵심 구현 | 검증 |
| --- | --- | --- | --- |
| 역할별 로그인·세션 철회 | `/login`, `/api/v1/auth/**` | `AuthService`, `JwtFilter`, `AuthSessionRegistryService` | `AuthApiIntegrationTest` |
| 로그인 공격 완화 | auth API | `AuthRateLimitService` | `AuthRateLimitPropertiesTest` |
| 유치원 tenant 격리 | `/kids`, `/classrooms`, `/notepad` | `AccessPolicyService`, tenant query | `PageAccessIntegrationTest`와 domain API tests |
| 원장 대시보드 | `/dashboard` | `DashboardService`, summary DTO | `DashboardApiIntegrationTest`, `DashboardPerformanceStoryTest` |
| 반·원생 운영 | `/classrooms`, `/kids` | classroom/kid service와 관계 entity | `ClassroomApiIntegrationTest`, `KidApiIntegrationTest` |
| 일일 출결 | `/attendance` | `AttendanceService`, bulk request | `AttendanceApiIntegrationTest` |
| 출결 변경 요청 | `/attendance-requests` | `AttendanceChangeRequestService` | `AttendanceChangeRequestApiIntegrationTest` |
| 출결 요청 멱등성 | `Idempotency-Key` | V18 unique migration | attendance request integration |
| 입학 신청 상태 처리 | `/applications/pending` | `KidApplicationReviewService`, `ApplicationStatus` | `KidApplicationApiIntegrationTest`, `WorkflowStateTransitionTest` |
| 알림센터 | `/notifications` | `NotificationService` | `NotificationApiIntegrationTest` |
| 외부 전달 Outbox | `/notification-outbox` | dispatch worker, channel registry | `NotificationOutboxIntegrationTest`, retry integration |
| Outbox claim 경쟁 | worker | `FOR UPDATE SKIP LOCKED`, stale reclaim | `NotificationOutboxClaimConcurrencyIntegrationTest` |
| 인증 감사 | `/audit-logs` | `AuthAuditLogService` | `AuthAuditRetentionIntegrationTest` |
| 업무 감사 | `/domain-audit-logs` | `DomainAuditLogService` | `DomainAuditApiIntegrationTest` |
| 알림장 성능 | `/notepad` | projection/query 개선 | `NotepadPerformanceStoryTest` |
| 대시보드 cache | `/dashboard` | Redis cache | `DashboardPerformanceStoryTest` |
| 운영 안전 설정 | prod startup | `StartupSafetyValidator` | `StartupSafetyValidatorTest` |
| 화면 접근성·보안 | SSR templates | label/ARIA, CSP, event delegation | npm 검사와 browser smoke |

## 검증 명령 묶음

```bash
./gradlew fastTest
./gradlew integrationTest
./gradlew performanceSmokeTest
npm run frontend:build
npm run accessibility:templates
npm run security:inline-handlers
npm run security:view-errors
npm run docs:links
npm run e2e:smoke
```

변경 영역에 맞는 targeted 검증을 먼저 실행하고, 릴리스나 큰 구조 변경 때 heavy 검증을 실행합니다.
