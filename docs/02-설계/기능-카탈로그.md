## 7. 화면과 frontend 품질

- Thymeleaf SSR과 HTMX fragment 갱신을 사용합니다.
- 페이지별 JS를 `static/js/pages/*`로 모듈화했습니다.
- inline event handler를 제거하고 CSP와 event delegation을 적용했습니다.
- Tailwind CDN을 제거하고 로컬 build asset으로 전환했습니다.
- label/ARIA 이름, 버튼 type, alt, reduced motion을 자동 검사합니다.
- 실제 화면 확인은 `npm run e2e:smoke`로 역할·모바일·KST 시간 흐름을 확인합니다.
