# 로컬 개발 워크플로

## 1. Docker 의존성 실행

```bash
cd /Users/alex/project/kindergarten-erp/erp
cp docker/.env.example docker/.env
docker compose --env-file docker/.env -f docker/docker-compose.yml up -d
docker compose --env-file docker/.env -f docker/docker-compose.yml ps
```

MySQL과 Redis가 실행된 뒤 서버를 시작합니다.

## 2. 데모 서버 실행

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
SPRING_PROFILES_ACTIVE=demo ./gradlew bootRun
```

브라우저에서 [http://localhost:8080/login](http://localhost:8080/login)을 열고 [로컬 데모 계정](로컬-데모-계정.md)을 사용합니다.

## 3. local 프로파일 실행

```bash
APP_SEED_ENABLED=true SPRING_PROFILES_ACTIVE=local ./gradlew bootRun
```

`demo`는 local 설정을 포함하고 시드와 Swagger를 자동으로 활성화하므로 면접 시연에는 `demo`를 권장합니다.

## 4. 확인 명령

```bash
curl -I http://localhost:8080/login
curl -i http://localhost:8080/actuator/health/readiness
```

## 5. 종료

서버는 `Ctrl + C`로 종료하고, Docker 컨테이너만 종료할 때는 다음을 사용합니다.

```bash
docker compose --env-file docker/.env -f docker/docker-compose.yml down
```

로컬 데이터를 지울 때만 `down -v`를 사용합니다. 자세한 환경 변수는 [`../guides/env-contract.md`](../guides/env-contract.md), 전체 시연 순서는 [`시연-시나리오.md`](시연-시나리오.md)를 참고합니다.
