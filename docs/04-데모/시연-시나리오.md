# 면접 시연 시나리오

전체 화면별 기대 데이터와 5분·10분 시연 순서는 [`../../guides/demo-scenario.md`](../../guides/demo-scenario.md)를 기준으로 합니다.

## 추천 5분 흐름

1. `principal@test.com / test1234!`로 로그인합니다.
2. `/dashboard`에서 유치원 운영 지표를 보여줍니다.
3. `/applications/pending`에서 `PENDING`, `WAITLISTED`, `OFFERED`, `APPROVED` 상태를 설명합니다.
4. `/notification-outbox`에서 실패 채널·검색·dead-letter retry를 보여줍니다.
5. `/audit-logs`와 `/domain-audit-logs`에서 인증·업무 변경 추적을 보여줍니다.
6. `parent1@test.com`으로 전환해 `/notepad`와 `/attendance`에서 자녀 범위를 보여줍니다.

## 설명 순서

```text
업무 문제 → 권한/tenant 경계 → 상태 전이 → 외부 실패 Outbox → 감사 로그 → 수치 기반 성능 개선
```
